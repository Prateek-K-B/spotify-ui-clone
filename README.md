# 🎶 Spotify UI Clone  

A static **Spotify UI Clone** built using only **HTML and CSS**.  
This project replicates the **look and layout** of Spotify’s web player, focusing purely on **frontend design** (no interactivity or backend).  

---

## 🚀 Features  
- 🎨 Clean and modern Spotify-inspired design  
- 📱 Responsive layout (adjusts to screen sizes)  
- ⚡ Built only with **HTML + CSS** (no JavaScript)  
- 🖼️ Static UI clone (design-focused, non-functional)  

---

## 🛠️ Tech Stack  
- **HTML5**  
- **CSS3**
